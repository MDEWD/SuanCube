# Next.js渐进式迁移计划

## 策略调整

1. 降级Next.js版本到更稳定的14.x版本，避免15.5.0的兼容性问题
2. 升级所有相关依赖到兼容版本
3. 渐进式迁移页面，确保每个页面都能正常工作后再迁移下一个
4. 使用客户端组件（Client Components）解决服务端渲染兼容性问题

## 具体步骤

1. **降级Next.js版本**

   * 安装Next.js 14.x版本（更稳定，与Ant Design兼容）

   * 更新next.config.js配置

2. **升级依赖版本**

   * 升级TypeScript到5.x

   * 升级Ant Design Pro Components到最新兼容版本

   * 更新其他相关依赖

3. **渐进式页面迁移**

   * 先迁移简单的静态页面（如Welcome首页）

   * 然后迁移有API调用的页面

   * 最后迁移复杂的动态页面

   * 每个页面迁移后立即测试

4. **解决兼容性问题**

   * 为Next.js配置Ant Design的SSR兼容

   * 使用动态导入解决组件兼容性问题

   * 调整API调用逻辑适配Next.js环境

## 预期结果

* 完成从Umi.js到Next.js的迁移

* 保持所有现有功能正常工作

* 利用Next.js的SSR提升SEO和性能
