# 测试账号说明

## 验证码登录测试账号

系统已内置三个测试账号，使用**不同的验证码**来区分不同角色：

### 1. 普通用户账号
- **验证码**: `123456`
- **角色**: `user` (普通用户)
- **功能**: 
  - 购买记录
  - 我的收藏
  - 需求管理

### 2. 算力同盟账号
- **验证码**: `123457`
- **角色**: `partner` (算力同盟)
- **功能**:
  - 我的商品
  - 出售记录

### 3. 管理员账号
- **验证码**: `123458`
- **角色**: `admin` (管理员)
- **功能**:
  - 所有订单
  - 用户管理
  - 算力同盟管理

## 使用方法

### 方法一：角色选择（推荐）
1. 访问登录页面 `/user/login`（验证码登录页面）
2. 在"选择测试角色"区域，选择要登录的角色（普通用户/算力同盟/管理员）
3. 验证码输入框会自动填充对应的验证码
4. 点击"登录"按钮即可登录

### 方法二：手动输入验证码
1. 访问登录页面 `/user/login`
2. 直接输入对应的验证码：
   - 普通用户：`123456`
   - 算力同盟：`123457`
   - 管理员：`123458`
3. 点击登录

### 方法三：账号密码登录（备用）
如果使用 `/user/login1` 页面（账号密码登录），可以使用以下账号：

- **普通用户**: `testuser` / `123456`
- **算力同盟**: `testpartner` / `123456`
- **管理员**: `testadmin` / `123456`

## 注意事项

- 这些测试账号在开发模式下，即使后端API失败也会使用模拟数据自动登录
- 如果需要在真实后端环境中使用，需要：
  1. 通过注册页面或API创建账号
  2. 由管理员将用户角色修改为对应的角色（`user`、`partner`、`admin`）

## 账号创建脚本

如果需要通过API批量创建，可以运行 `scripts/create-test-accounts.js` 脚本。
